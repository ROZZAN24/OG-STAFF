Generate Staff ID Card

Sign institutional employee records with hardware-grade RSA-2048 digital signatures and create Code 128 barcode identity cards.

⚠
Educational demo only: This application stores the private signing key in your browser's LocalStorage. Anyone with physical access to this browser profile or storage may be able to extract it. Production identity systems must protect signing keys using a secure server, an HSM (Hardware Security Module), or a dedicated KMS.
