OG STAFF — Identity Verification System

Generate tamper-evident staff ID cards and verify their authenticity using RSA digital signatures and SHA-256. Built with browser-native Web Crypto for security laboratory research and viva examinations.

ℹ
Local Server Execution Architecture: This application requires no external backend database or cloud server API. However, because modern browsers mandate a Secure Context for the W3C Web Crypto API (`window.crypto.subtle`) and camera barcode scanning, this project must be run from a local HTTP server such as python -m http.server 8080 on http://localhost:8080.
🔑

RSA-2048

RSASSA-PKCS1-v1_5 asymmetric cryptography with a 2048-bit modulus and public exponent 65537, producing a 256-byte digital signature.

⚡

SHA-256 Hashing

Cryptographic digest that maps canonical staff data to an unforgeable 256-bit hash, exhibiting a strict avalanche effect upon any alteration.

🛡

Web Crypto API

100% real browser-native cryptographic operations executing directly in hardware/OS primitives. No simulated or hardcoded results.

📊

Code 128 Barcodes

Traditional 1D high-density barcode tokens with live camera scanning (ZXing) linked to cryptographically verifiable digital records.

⚖ Educational Concept: Digital Signatures vs Encryption

A common misconception in security lab examinations is confusing encryption with digital signing. Both utilize RSA asymmetric keys, but they solve fundamentally different problems:

Digital Signature (Used Here)

  • Purpose: Authenticity, Data Integrity, Non-repudiation.
  • Signing Key: Sender's Private Key.
  • Verification Key: Sender's Public Key (known to all verifiers).
  • Visibility: Plaintext remains readable. Anyone can inspect staff details.
  • Guarantee: Proves the data was issued by the genuine keyholder and has not suffered even 1 bit of tampering.

Data Encryption (Confidentiality)

  • Purpose: Confidentiality & Privacy.
  • Encryption Key: Recipient's Public Key.
  • Decryption Key: Recipient's Private Key.
  • Visibility: Plaintext is concealed (ciphertext looks like random noise).
  • Distinction: On an ID card, staff details must be physically readable by security guards, making digital signatures the correct technology.
